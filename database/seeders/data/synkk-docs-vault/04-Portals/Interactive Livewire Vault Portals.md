# 🌐 Interactive Livewire Vault Portals (Milestone B)

Obsidian Publish is convenient but rigid—it locks you into a fixed theme, lacks custom interactivity, and charges monthly per-vault fees.

Synkk's **Interactive Livewire Vault Portals** give you complete creative and architectural control over how your knowledge base is shared with the world.

---

## 🎨 4 Curated Design Presets

Every portal can be styled in one click using carefully crafted aesthetic themes:

1. **Obsidian Clean (`obsidian-clean`)**:
   - Matches the familiar Obsidian desktop aesthetic.
   - Collapsible sidebar folder tree, breadcrumb trails, and inline wikilink popovers.
2. **Enterprise Documentation (`enterprise-docs`)**:
   - Modern technical documentation layout with left sidebar API hierarchy, center article view, and right-hand "On This Page" table of contents.
3. **Digital Garden (`digital-garden`)**:
   - Organic knowledge exploration with interactive bidirectional backlink graphs and visual note connectivity.
4. **Minimalist Blog (`minimalist-blog`)**:
   - Typography-first, distraction-free reading experience optimized for essays, newsletters, and long-form writing.

---

## 🔒 Access Control & Security

- **Public Portals**: Accessible to anyone via `/p/{slug}` or custom subdomains.
- **Team-Restricted Portals**: Only authenticated members of your Synkk team can view notes.
- **Password-Protected Portals**: Gated with a custom passphrase using bcrypt hashing.

---

## ⚡ Real-Time Features

- **Live Search**: Client-side and server-side fuzzy search across all published notes in milliseconds.
- **Instant Publishing**: Sync a note in Obsidian, and it is immediately live on your portal—no static site generators, build scripts, or CI/CD pipelines required!
