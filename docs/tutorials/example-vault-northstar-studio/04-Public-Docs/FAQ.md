# ❓ Frequently Asked Questions

Back to home: [[04-Public-Docs/Welcome to Northstar|Welcome to Northstar Studio Docs]]

### Where are these docs authored?
Right inside Obsidian as plain `.md` files. Every time our team syncs changes to Synkk, this public portal updates automatically.

### Can we protect a portal with a password?
Yes — Synkk Portals support public access, team-only access, or an optional bcrypt password gate (minimum 8 characters).

### How do AI tools read our documentation?
Point any LLM or agent at `/p/<portal-slug>/llms.txt`, or use the built-in **Ask This Portal** drawer when enabled.
